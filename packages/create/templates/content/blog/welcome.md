This starter keeps the blog content directory present so the default content
plugin configuration can build immediately. Write your own markdown files
here — frontmatter `title`, `date`, `tags`, and `excerpt` are picked up by
the blog index and the `/blog/:slug` page automatically.

The post page renders the frontmatter `title` as the page's H1 heading, so
keep the body's headings starting at `##` — a leading `# Heading` in the
markdown body would render a duplicate page title.
