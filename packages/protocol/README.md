# @openelement/protocol

Shared dependency-neutral contracts for the OpenElement framework. Most
application authors should start with `@openelement/app` and `@openelement/element`;
this package exists for adapters and advanced integrations that need stable
typed contracts for rendering, routes, signals, build plans, and artifacts.

The package contains types plus small host-API-free runtime values. It does not
choose a renderer, bundler, deployment platform, or mutable signal engine.

## Install

```bash
npm install @openelement/protocol
```
