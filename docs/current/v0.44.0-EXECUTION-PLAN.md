Implementation and repair packets state exact writable paths, RED/GREEN commands,
push tier, and forbidden changes. Ordinary failures return to the implementer.
Verifier failure invalidates the candidate, requires a new implementation SHA and
new exact-SHA CI, and is followed by another fresh verifier session.

reports. Repository current state contains only durable manifests and compact closure
references.

Integration uses the authorized pull-request path and a fast-forward check (`--ff-only`)
where local topology is inspected; history is never force-pushed.
