# Goal: accelerate the v0.44 Alpha architecture train

Close the minimal unpublished Alpha.0 foundation, freeze one shared compiled-element
contract, run subsystem implementation in parallel, integrate serially, and produce
one coherent Final Alpha candidate. Do not let postponed repository hardening block
compiler/runtime architecture.

## Scope

1. Complete #1193 minimum branch safety and record one exact integration base SHA.
2. Freeze the Part Program, DOM marker/claim, runtime ownership and Island boundary
   contracts in code/types/tests plus one short current document.
3. Establish explicit path ownership for Compiler, Runtime, SSR/Claim and App/Delivery.
4. Start Compiler, Runtime and SSR/Claim lanes in separate branches/worktrees from the
   same SHA.
5. Perform Integration I before broad App/Delivery implementation.
6. Continue parallel second-wave work, perform Integration II, remove replaced primary
   architecture, and run Final Alpha qualification.

#1156, #1187, #1188 and #1189 belong to Beta.3 under #1192. #1157, #1158 and
#1159 belong to Beta.2. Do not implement them as Alpha prerequisites.

## Authority

The thinker owns cross-lane contracts, dependency topology, path ownership,
dispatch, integration branches, conflict arbitration, complete diff review and
checkpoint qualification. Executors own implementation only inside assigned paths
and may not merge their own lane to `dev` or change a frozen cross-lane contract.

Exact executor identity and invocation live in executable configuration outside
documentation. An unavailable executor is reported exactly; ownership is explicitly
redistributed rather than silently substituted.

## Verification

- Lane work runs targeted package/type/fixture tests only.
- Integration I and II run cross-lane integration harnesses but no publication
  ceremony.
- Only integration-to-`dev` pull requests run authoritative exact-SHA full CI.
- Final Alpha adds packed consumers, browsers/runtimes, performance, migration,
  interoperability, legacy-absence checks and fresh independent verification.
- Raw agent transcripts and per-attempt evidence are not committed.

## Stop conditions

Stop only for an unresolved cross-lane architecture/public-API/security decision,
missing required branch authority, unavailable required executor without an explicit
redistribution decision, destructive-history request, repeated proven infrastructure
blocker or user interruption. Ordinary lane, integration, test and CI failures enter
repair loops.

Alpha.0 remains strictly unpublished. Do not begin Beta.1 from this Goal until Final
Alpha qualification succeeds.
