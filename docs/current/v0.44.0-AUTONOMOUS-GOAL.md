# Goal: complete v0.44 Alpha as an internal parallel workspace train

Finish the v0.44 framework architecture quickly by assigning internal Alpha work
packages to independent workspaces and agents, then aggregating them once in a final
integration workspace. Do not activate the three-role release loop during Alpha.

## Objective

1. Finish #1193 minimum history safety.
2. Freeze one small code-first cross-workspace contract and real path ownership.
3. Record one exact common base SHA.
4. Create alpha.1 through alpha.7 as independent workspaces from that SHA.
5. Give one agent end-to-end ownership of each workspace's code, tests, commits and
   branch.
6. Run the seven workspaces concurrently with targeted RED/GREEN gates.
7. Use alpha.8 as the sole integration workspace and agent.
8. Produce one coherent exact-SHA Alpha integration PR to `dev` and pass its
   authoritative full CI.

## Alpha execution rule

Alpha numbers are internal work identifiers, not published versions. Alpha has no
thinker/implementer separation, no release verifier, no unanimous release GO, and no
per-workspace release ceremony. A workspace agent implements and verifies its owned
slice directly. The alpha.8 agent performs final aggregation and integration repair.

Do not tag, publish, update a dist-tag, create a GitHub Release, promote `main`, or
claim a public Alpha release.

## Workspace safety

- Separate worktree and branch per workspace; never two writers in one checkout.
- Disjoint production-path ownership wherever possible.
- Shared contract changes require an explicit cross-workspace update before code
  proceeds.
- No fallback architecture, hidden compatibility, weakened tests, workspace aliases,
  private cross-package imports or unsupported claims.
- Workspace agents run focused tests and the fast push tier, not the full matrix.
- Alpha.8 consumes exact workspace SHAs and owns the only full-CI integration PR.

## Deferred work

#1156, #1187, #1188 and #1189 remain Beta.3 under #1192. #1157, #1158 and #1159
remain Beta.2. They do not block Alpha.

## Completion

This Goal completes when alpha.8 is fast-forwarded to `dev` at its exact green PR SHA,
all Alpha issues have concise GitHub closure evidence, and the integrated framework is
ready to enter Beta.1. The three-role release loop starts only in the Beta Goal.
