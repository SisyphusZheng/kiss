# v0.42.0-alpha.5

## Audit round 1 remediation

The fifth alpha of the 0.42 line — unplanned in the original
four-alpha shape, inserted by the first implementation audit of the WC
Application Loop (TP-5.5, 35 issues #539–#573). It ships no new
semantics beyond the ADR-0121 amendment; it closes the audit's protocol
holes, rewrites the morph client, and sweeps the line's evidence
honesty.

- **The headline root cause**: the alpha.3 morph enhancement never
  fired. The `submit` event is not composed and page content lives
  inside page-element DSD shadow roots, so the document-level submit
  listener never saw an enhanced form — every "enhanced" page was
  silently using the native no-JS path, and the two island-survival
  specs fail deterministically at both prior tags. The client is
  rewritten around per-shadow-root submit interception and
  shadow-content morphing; the survival matrix is now mechanically true
  and documented cell-by-cell in
  [`docs/current/MORPH_CONTRACT.md`](https://github.com/open-element/openelement/blob/main/docs/current/MORPH_CONTRACT.md).
  Errata are appended to the alpha.3 and alpha.4 notes.
- **Protocol (ADR-0121)**: the prerender hard rule covers named
  `actions`; named-action dispatch is own-key gated (`?/constructor` is
  a defined 404); one `x-openelement-action` header (`true` =
  ActionResult JSON, `enhance` = HTML morph) with `Vary`; an action
  returning a `Response` is a contract violation, never a response; the
  default PRG strips the `?/name` marker and keeps other query
  parameters; every 3xx coerces to 303 on POST and `redirect()`
  validates its status; fetch callers always receive ActionResult JSON
  (404/500 included, production-scrubbed); request-time responses carry
  `Cache-Control: no-store`; POST takes the same error boundary as GET;
  action POSTs get a 10 MB body limit; non-GET/POST methods answer 405
  with `Allow`.
- **Morph continuity**: form-scoped `data-open-region` targeting
  (submitter `data-open-region-target` wins) with navigation fallback,
  id-keyed + lookahead identity matching, popstate reload,
  `open:action-failure` restored as a cancelable hook, the submitter's
  name/value preserved in the enhanced body, 500/cross-origin responses
  navigate instead of morphing, double-submit guard, fragment
  preservation, `<details>`/media state protection.
- **Evidence**: the request-time fixture suite (42 tests) runs on
  Chromium, Firefox and WebKit in the ci and release gate tiers;
  `check:static-output-freeze` proves build determinism in the release
  tier; a dev(hono) vs build(Nitro) parity contract test boots both
  real servers; the performance baseline records its environment
  (`docs/release/v0.42.0-alpha.5-performance.json`).
- **Also fixed**: dev SSR crashed on every route (the `customElements`
  polyfill now ships to the dev entry); `[...path]` request-time routes
  and a self-contained `matchRequestTimeRoute` host contract; zero-island
  apps with enhanced forms (and the complement: the enhancement layer is
  emitted only when enhanced forms exist, so island-only sites keep
  their lean bundle); the starter's `/contact` (it was never shipped in
  `TEMPLATE_FILES`) now builds and is POST-smoked in consumer CI;
  SPA vs request-time loader/action types (`SpaLoader` et al.) and a
  bilingual guide page for the CSRF threat model.

- Full unit suite 971 passed; dev/build parity contract 6/6; AutoFlow3

  303 PRG) through Nitro node; `check:static-output-freeze --self-check`
  passes (422 files byte-identical across builds).

## Migrating from alpha.4

- Pure-static sites: nothing to do; the client bundle stays lean
  (the enhancement layer is emitted only when enhanced forms exist).
- Request-time routes: forms using the enhancement keep working; the
  `x-openelement-enhance` header is retired — custom clients should send
  `x-openelement-action: true` (ActionResult JSON) or `: enhance` (HTML).
- Actions must no longer return `Response` objects (contract violation);
  return data/`fail()`, or `throw redirect()`. `redirect()` accepts only
  301/302/303/307/308 and coerces to 303 on POST.
- `open:action-failure` (advertised in alpha.2, silently absent since
  alpha.3) is restored as a cancelable hook; see MORPH_CONTRACT.md.
