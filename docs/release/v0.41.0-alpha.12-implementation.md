## Detailed changes

### #428 — element core runtime

- `signal-context.ts:58-71`: replace the `host?.getRootNode?.()` reset with a
  `lastNode` tracker. When `current.parentNode` is null, derive the next node
  from `lastNode.getRootNode()` (the last real node visited), so each shadow
  boundary is crossed exactly once and the loop terminates at the document root.
- `error-boundary.ts:67`: `onclick` → `onClick`.
- New `signal-context.test.ts`:
  - provider in outer tree is found from inside a shadow root (cross-boundary).
  - consuming an unprovided context inside a shadow root returns the default
    signal WITHOUT hanging (assert it resolves within a timeout / finite loop).

### #427 — adapter-vite SSG / build

- `external-resolver.ts:348-352`: `execFileSync('deno', ['info', '--json', probePath], { cwd, maxBuffer, timeout })`.
- `ssg-helpers.ts:67`: replace single space→`%20` with ordered encoding
  `%` → `%25`, then `#`→`%23`, `?`→`%3F`, `&`→`%26`, ``→`%20`. `@` preserved.
- `build-plan.ts:63,106`: `plan.output.root ?? (typeof Deno !== 'undefined' ? Deno.cwd() : process.cwd())`.

### #424 — contract checker correctness

- `check-type-safety.ts`: import `stripCommentsLine`; in `scanSourcesForAnyIssues`
  strip each line (tracking block state) before `isCodeLine` + pattern match.
- `check-architecture-contract.ts`: import `stripCommentsLine`; `failMatches`
  strips inline comments (tracking block state) per line before `re.test`.
- `check-package-artifacts.ts:109`: `hostScanAllowed = !firstCodeLine.trim().startsWith('// deno-api-free:ignore')` where `firstCodeLine` is the first non-empty line (`text.split('\n').find(l => l.trim() !== '')`).
- `check-deno-api-free.ts:34`: same first-non-empty-line restriction.
- `i18n-plugin.ts`: line 1 becomes `// deno-api-free:ignore`; keep doc block after.
- `check-critical-path-tests.ts`: for each evidence entry, run the suite:
  - `.test.ts` → `deno test --allow-all <file>`, assert exit 0 and expected test names present.
  - `tools/nitro-proof.ts` → run both `node` and `workers` presets (`deno run --allow-all tools/nitro-proof.ts <preset>`), combine output, assert `node-server` + `cloudflare-module` present.
  - `www/e2e/dsd-layers.spec.ts` → `deno test --config www/e2e/playwright.config.ts <file>`; if the browser binary is missing, report a clear SKIP (not a failure).

### #426 — release tooling tests

- `publish-npm.ts`: `export function deriveDependencies(pkg, allPackages, io?)` with a
  `DeriveDepsIo` injection (`readPkgJson` / `readRootJson` / `readSrcFiles`) so it is
  pure-testable; throw when an `npm:` dependency has no resolvable version
  (replace `?? '0.0.0'`). `main()` is now guarded by `import.meta.main`.
- `bump-version.ts`: `export function parseVersion`, `export function validateVersionStep`.
- New tests cover the four `package-graph` functions, `deriveDependencies`
  (normal + missing-version throw), and `parseVersion`/`validateVersionStep`
  (base regression + prerelease rollback).

### #425 — coverage measurement

- `coverage-summary.ts`: `isProductionPackageSource` now combines `isPackageSource`
  (`packages/*/src`) and `isToolsLibSource` (`tools/lib`); `parseLcov` takes an
  `include` filter (defaults to the combined scope) so each scope is measured alone.
- `check-coverage.ts`: compute `packages/*/src` and `tools/lib` scopes separately;
  apply 69/81/72 to packages, and an initial `tools/lib` threshold
  (lines 50 / branches 50 / functions 50, raised later) via `--tools-*` flags.
- New `coverage-summary.test.ts` asserts scope separation and `__tests__` exclusion.

## Gates (must be green before PR)

`deno task test` · `deno task typecheck` · `deno task lint` ·
`deno task test:coverage:check` · `deno task build` (Node smoke).

## Release flow after merge to `dev`

1. PR `alpha.12 → dev`, wait for `opencode-review` bot, fix any 🔴/🟡.
2. Merge to `dev`; create `dev → main` PR.
3. `gh workflow run autoflow-release.yml --ref main -f version="0.41.0-alpha.12" -f plan="minor"`.
4. Verify npm + git tag + GitHub prerelease agree.
