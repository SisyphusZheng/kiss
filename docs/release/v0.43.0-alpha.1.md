# v0.43.0-alpha.1

Foundation train for the 0.43 line (Universal WC SSR + diagnostics +
recipes), on top of the frozen 0.42.0 — plus the post-freeze project-wide
health check. No ADR-0119/ADR-0122 frozen semantics change in this release.

## Highlights

- **Hydration-mismatch diagnostics (#631)**: SSR/hydration mismatches now
  report a stable code (`OPEN_ELEMENT_HYDRATION_MISMATCH`), the divergence
  reason (marker-count / branch-count / branch-token), host tag, expected
  vs actual marker counts and branch-token sequences with the divergence
  index — multi-line detail in dev, one coded line in production. The
  degradation behavior (client-side re-render) is unchanged.
- **Cross-runtime dist/server (#969)**: request-time builds emit
  `dist/server/package.json` (`{"type":"module"}`), and both `serve.mjs`
  and `index.js` carry a URLPattern runtime-floor guard — Node < 24 fails
  fast with a clear guided error (polyfilled from `node:url` on 23.8+)
  instead of a raw `SyntaxError`/`ReferenceError`. The honest floor is
  **Node 24+** (Deno and Bun unchanged); docs corrected. New CI job
  `node-serve-smoke` boots the fixture server on Node 24 and asserts the
  clean error on Node 20.
- **Registration collision hard-fails (#971, alpha.2-scheduled, landed
  early)**: a definePage route whose self-registered content element tag
  equals the route's path-derived fallback tag never worked correctly (the
  page render is bypassed) — the 0.42.x scanner warning is now a build
  error with rename guidance. The starter's freshness route was itself on
  the collision shape and is renamed to `freshness-view`.
- **Third-party WC SSR corpus**: new `deno task third-party-wc:corpus`
  pins the SSR output form of Lit/Shoelace/Material/bare-native components
  and writes a machine-readable record
  (`docs/evidence/third-party-wc-ssr-corpus.json`) — the input signal for
  the 0.43 admission work (#979).
- **Recipes (verified against real builds)**: rate-limit middleware
  (#627), FileDataAdapter on the unstorage read shape (#629), and a
  better-auth guard middleware template (#630) — all under
  `docs/integrations/`.

## Fixes from the health check

- Fetch action channel no longer 500s on unserializable `fail()` data —
  the 422 body degrades to `data: null`, preserving the two-channel
  symmetry (ADR-0122 §2).
- Prerendered dynamic routes honor the route's own `head.title` (#968).
- Preact recipe documents explicit import-map entries (#970 — the prefix
  form fails in standalone consumer projects on Deno 2.9).
- CHANGELOG backfilled: 0.42.0 stable, alpha.11–15 and 0.41.0-alpha.12
  entries (#964).
- Governance: SSR registry markers chartered in the element protocol layer
  (#965); build-package host-API rule scoped to source vs generated output
  (#966); arch-gate metadata-boundary message aligned with the deliberate
  regex scanning (#967); remaining shared logger tags differentiated
  (#623).

## Upgrade notes

- From 0.42.0: bump the `@openelement/*` specifiers to `0.43.0-alpha.1`.
- If a definePage route module names its content element exactly after the
  route file's derived tag (e.g. `contact.tsx` + `'contact-page'`), the
  build now fails — rename the content element (e.g. `contact-form-view`).
- `dist/server` requires Node 24+ (Deno/Bun unaffected).
