## Compatibility changes

- `defineLayout` is removed; author layouts with `defineElement`.
- Removed reflected attributes restore their declared static-prop defaults.
- Prop getters continue to return Signals as an intentional authoring contract.
- Action failures expose a stable generic page error; raw errors stay in
  development logs.
- `ApplicationElement` rejects unknown members and public `__internal_*`
  data-context exports are removed.
- The default locale uses canonical unprefixed routes; non-default locales use
  explicit prefixes.
- Generated starters map Element, `jsx-runtime`, and `jsx-dev-runtime` to the
  exact release line.
- npm verification supports alpha, beta, and rc dist-tags.

## Required gates

- Per implementation PR: targeted tests, format, lint, typecheck, critical
  paths, coverage, build, affected Nitro/consumer/package/E2E gates, and remote
  AutoFlow.
- Integrated `dev`: `deno task autoflow:ci`, full build, Chromium functional and
  visual matrix, Firefox/WebKit functional matrix, Nitro Node/Workers, local and
  packaged consumers, core/third-party smoke, package artifacts, pack and npm
  publish dry-runs, repeated from a clean worktree.
- Release prepare:
  `deno task autoflow:release-prepare --to 0.41.0-alpha.13 --approved-plan docs/release/v0.41.0-alpha.13-plan.md`.
- Release PR: `dev → main`, then main AutoFlow, CodeQL, and deployment checks.
- Publish: dispatch `autoflow-release.yml` for `0.41.0-alpha.13`, verify all five
  npm packages and the `alpha` dist-tag, then run fresh Deno, Node ESM, starter,
  Nitro Node/Workers, third-party WC, and jsDelivr consumers.
