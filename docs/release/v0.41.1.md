# v0.41.1

## Tooling hardening patch on the stable line

`0.41.1` is the first patch on the stable `0.41.x` line. It carries the
fixable set from the third-party audit: tooling hardening and repository
hygiene only — **no public API, package-topology or runtime-default
changes**, so the ADR-0119 freeze surface is untouched and no migration
step is required.

## What changed

- **Shared path constants**: adapter-vite's `dist`/`.openElement` magic
  strings converge on `internal/paths.ts`
  (`DEFAULT_OUT_DIR`/`OPEN_ELEMENT_DIR`), and `tools/lib/fs.ts` gains
  shared `readText`/`readJson` helpers now used across ten tooling files.
- **Repo-hygiene gate**: now scans credential files and credential-shaped
  content, and rejects tracked binaries over 1 MiB outside intentional
  design/e2e/fixture locations.
- **vite 8.0.10 → 8.0.16** across the root, the examples and adapter-vite —
  the adapter-vite pin lag was the hidden cause of a tsc crash on
  dual-config typechecks.
- **Stable-line version guards**: www-truth retires the same-base alpha
  line instead of disabling itself on stable versions, the publish dry-run
  skips already-published versions, and stale-claim fixtures no longer
  assume an alpha current line. `CONTRIBUTING.md` records the
  `no-sloppy-imports` rationale; stale merged branches were pruned.
