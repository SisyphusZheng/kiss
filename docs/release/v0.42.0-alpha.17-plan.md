## Scope

The last alpha before the TP-6 stable freeze decision (#962):

1. **#960 — registration decoupling (Option 2, ADR-0128)**: definePage route
   modules register their page class under the route-path-derived fallback
   tag; the `tagName` export is ignored for registration and only names the
   content element. Breaking SSR markup change on the unfrozen alpha
   surface: shape-1 pages gain one wrapper element (the fallback-tag page
   element around the content element).
2. Architect-review fixes (17 commits, all gated):
   - element: bare-tag fallback never throws on throwing-getter props;
     depth-limit trip no longer logs once per function-component frame;
     single-sourced fallback shape.
   - adapter-vite: serve.mjs CSS Content-Type parity with static-serve;
     missing-tagName scanner note silenced for .mdx routes.
   - docs: #961 planning anchors, CHANGELOG alpha.16 gap-fill, package
     README anchors, SPA index.html contract correction, serve.mjs in the
     deployment guide, guide samples aligned with the sanctioned route
     pattern.
3. Blog e2e round-6 closed (#963): zero-wiring rebuild from the published
   alpha.16, all round-5 candidates dispositioned.
