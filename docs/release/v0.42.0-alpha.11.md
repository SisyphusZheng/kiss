# v0.42.0-alpha.11

Round-5 full-spectrum audit remediation train. All 78 findings from the
2026-08-01 round-5 audit (issues #730–#809) are fixed in this release; the
audit report lives at `docs/audit/2026-08-01-round5-audit.md`.

## Highlights

- **Security**: `validateSafeUrl` tab/newline bypass closed (module-script
  `data:` XSS, #761); desktop examples bind loopback only and the reader's
  LAN-reachable arbitrary file read + remote kill are gone (#777); Mastodon
  example no longer caches API errors as data (#775).
- **Correctness**: a guard-vetoed redirect during navigation now keeps the
  current page's loader data instead of clearing it (#802);
  `useLoaderData<T>()` honestly types `T | undefined` (#763); theme broadcast
  no longer clobbers host-owned `data-theme` (#773); disconnect→reconnect no
  longer resets non-reflected prop state (#772); JSX callback `ref` is
  consumed (#756); `open-button` anchor-mode disabled sync works in both
  directions (#757); `open-input`/`open-badge` observe dynamic attribute
  changes correctly (#769, #770); blog locale fallback direction fixed
  (#759); three site-ui components that rendered as empty shells are now
  registered (#758); page-rail scroll-spy active state applies (#779).
- **Honesty over surface**: the homepage flagship example is real compilable
  API (#762); dead options, dead config keys and misleading types removed
  across element/app/adapter-vite (#764–#768, #771); docs synced with code
  reality (ROADMAP registry, ADR catalog 0087–0090, drizzle recipe,
  BROWSER_BASELINE).
- **Repo hygiene**: `.githooks` are executable again so local gates cannot be
  silently skipped on a fresh clone (#760); duplicated tools helpers (static
  smoke server, tarball naming, `normalizeDep`) single-sourced; dead JSR
  publish channel removed; ~40 dead exports / dead files swept.
