# v0.43.0

Stable cut of the 0.43 line — **Universal WC SSR** plus the **OpenElement ×
Supabase × Cloudflare** delivery path, frozen under ADR-0135. Content
identical to the published 0.43.0-alpha.2 train (108 commits over alpha.1);
this cut promotes it to `latest`. The frozen 0.41.x/0.42 contracts
(ADR-0119/ADR-0122 and their amendments) are untouched; frozen-path touches
on this line each carry an amendment ADR (ADR-0131, ADR-0133, ADR-0134).

## Highlights

### Supabase × Cloudflare reference starter (new) — #981/#983

`examples/supabase-cloudflare-starter`: a complete reference SaaS that
builds with this framework, deploys to Cloudflare Workers, and is verified
end-to-end against a real Supabase project
(`https://openelement-ref-starter.freemanzheng.workers.dev`).

- **Auth & identity (#998/#1047)**: email/password + GitHub OAuth login,
  cookie session write-back through the Nitro `cloudflare_module` bridge,
  CSRF floor via `c.env` on Workers (the alpha.3 risk spike, #981),
  RLS-guarded loaders, logout, role + revocation evidence. An unconfigured
  OAuth provider fails closed (422 + "not configured"), never a 500.
  `admin_audit` writers, rate limiting, and production SMTP via Resend on
  the dedicated `auth.openelement.org` sender — signup confirmation
  verified end-to-end on real mailboxes (SPF/DKIM/DMARC all pass).
- **Data**: migration delivery + drift gates (#1008); owner-scoped Storage
  with an atomic upload/download/delete lifecycle (#1009); insert-only
  Storage policies proven against the provider (#1013).
- **Realtime**: notes live island with isolation and post-reconnect
  delivery evidence (#1012), explicit duplicate-submit + second-client
  delivery proof (#1045).
- **Payments (#1001/#1048)**: durable Stripe webhook core (#1016),
  idempotent one-time Stripe Checkout (#1017), durable payment Queue + DLQ
  - replay (#1018), eligibility rules, redacted logs, deploy probes,
    runbooks.
- **Attachment scanning (#1019)**: fail-closed private-attachment scanner
  with scan dead-letter replay (#1014) — with no scan engine configured,
  uploads stay `pending_scan` and are undownloadable by everyone, by
  design. Queue/DLQ/scanner/Cron provisioning is gated (#1011).

### Three-tier fullstack CI evidence — #984/#997

- **Tier 1 (PR-safe)**: boundary gate on the built reference starter — the
  deployable public dir carries no server implementation and no secret
  values.
- **Tier 2 (real project)**: real-browser Supabase journey — signup, login,
  RLS, realtime, storage (#1005) — plus role and revocation evidence
  (#1007).
- **Tier 3 (weekly)**: real Workers deploy + live URL assertions; the
  release evidence-freshness gate keeps later releases on current-SHA
  provider evidence (#997, amended by ADR-0134 to admit newer manual runs).

### Universal WC SSR admission — #979/#1020

Third-party Web Component tags are now visible to SSR admission (#979 —
every consumed foreign tag is scanned/classified/recorded with a
deterministic path and reason), and the universal admission evidence corpus
is expanded across native, Lit, FAST, Stencil, Shoelace and Material Web
(#1020), with hydration-mismatch structured diagnostics (#631).

### Framework fixes

- **element**: SSR context walk, DSD attribute escaping, pre-hydration
  click cap (#1050); a `For` item's identity getter is read exactly once
  per render; depth-trip errors carry an ancestor component path (#975).
- **adapter-vite**: unified `node:http` bridge — multi `Set-Cookie`
  preserved, request URL built from the validated Host; Cloudflare Workers
  env extracted from `req.runtime.cloudflare.env` in nitro-mount (#981);
  response-header channel for loaders and actions (ADR-0129); catch-all
  route params resolve through SSG prerender (#1043); empty 200 text/html
  action responses navigate instead of morphing to blank (#974); dev
  rescan divergence + route varName collision fixes (#1051).
- **app**: programmatic SPA navigations are latest-wins (#1044); two
  client-router guard-concurrency defects on the frozen path fixed with
  regression tests (amendment ADR-0133, hygiene sweep #1076); router
  edge-case and runtime-verification batch (#1054).

### Hardening, audits, release tooling

- Deep-scan batches #1022–#1039 and #1055–#1068 (12 issues, incl. storage
  insert-only convergence), the 46-of-47 refactor batch (#1069), and the
  pre-release hygiene sweep (#1076, 12 findings).
- Release tooling: evidence-record IO extracted from release.ts (#907);
  evidence-freshness gate + tier-3 weekly schedule (#997); a failed
  unpublished attempt no longer deadlocks the state-machine gate (#1082);
  publish-existing un-stuck after evidence pushes and the starter lockfile
  folds into the bump commit (#1083/#1085).
- Evidence-train hardening (#1072–#1079): browser-journey assertion shape,
  queue enumeration via the Cloudflare API, realtime re-seed on a bound,
  storage CDN delete-invalidation tolerance, runner apt-mirror resilience.
