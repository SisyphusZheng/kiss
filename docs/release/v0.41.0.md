# v0.41.0

## The first stable five-package release

`0.41.0` is the stable release of openElement, the Web Components-native,
static-first application framework. Under ADR-0119, the interface freeze
covers `defineElement`, `definePage`, `buildApp`, the five-package graph
(`element`, `app`, `adapter-vite`, `create`, `ui`), the supported subpaths of
`docs/current/PACKAGE_SURFACE.md`, and the static/SPA semantics of
`defineApp` as shipped. Request-time data, forms, sessions and cache remain
explicitly unfrozen until 0.42 (WC Application Loop) and 0.44 (Production
Runtime). The #390 external adopter pilot was retired by maintainer decision
after zero recruitment across three release cycles — recorded as an explicit
exception in ADR-0119, not replaced with internal evidence.

## Migrating from the alpha line or 0.40.x

The aggregate, entry-by-entry migration guide lives in
[`docs/release/v0.41.0-migration.md`](https://github.com/open-element/openelement/blob/main/docs/release/v0.41.0-migration.md)
and on the site at `/guide/migration`. Breaking changes since 0.40.x:

- **0.40.x → alpha line**: eleven packages collapsed to five
  (`element`/`app`/`adapter-vite`/`create`/`ui`); `core`, `signal`, `router`,
  `protocol`, `content` and `ssg` are retired imports. Author with
  `defineElement`/`definePage`/`defineApp`; build with `buildApp()`.
  `defineLayout` removed. Distribution is npm-first.
- **alpha.17**: build-time helpers moved to `@openelement/element/build-utils`;
  router types (`RouteConfig`/`RouterInstance`/`RouterMode`) left the app root.
- **alpha.18**: dead exports/fields/scripts removed; `renderIntent.streaming`
  removed; dynamic-route render failures fail the build by default
  (opt out with `dynamicRouteFailure: 'warn'`).
- **alpha.19**: element root `export type *` star seams closed —
  `SafeHtml`/`UnsafeHtml`/`StyleSheetRule` no longer root exports; element
  internal `open-element-render`/`open-element-hydration` subpaths pruned;
  remaining ui `*TagName` re-exports removed; **ui controls are squared**
  (`--btn-radius`/`--badge-radius`/`--ui-control-radius`: round → 6px,
  visual breaking change).
- **0.41.0**: adapter-vite internal subpaths pruned (`app-vite`,
  `build-context`, `head-injection`, `i18n-plugin`, `plugin`,
  `generated-data-resolver`, `plugin-mdx`, `route-manifest`,
  `cli/build-client`, `cli/build-ssg`) — use the root, `nitro-mount`,
  `cli/build` and `sitemap`.

## The road from 0.40.x to stable

- **alpha.1–4** — npm-first publishing with provenance; the protocol layer
  becomes type-only; `HydrationScope` extracted; third-party Web Component
  interop gates (Lit/Shoelace/Material); Fresh reverse interop and the light
  `hydrateOpenElement` runtime.
- **alpha.5–8** — SPA mode (`defineApp({ mode: 'spa' })` with the
  loader/action/form chain), Deno Desktop targets, BuildPlan build evidence,
  ui token/primitive/composite layering.
- **alpha.9–10** — the five-package convergence (ADR-0113): one consumer
  graph, `buildApp()` as the single build boundary, ui rebuilt around proven
  primitives; dependency materialization restores Node ESM installs.
- **alpha.11–15** — SPA contract fixes, i18n canonical routes, trie-compiled
  routing, exact-version starters, honest two-stage release evidence, the
  five-package interface snapshot for the freeze rehearsal, #390 pilot kit.
- **alpha.16** — first audit reset (ADR-0116): SSR/hydration event-marker
  alignment with mismatch fallback, `observedAttributes` merged at class
  definition time, base64url island chunk matching, npm `latest` dist-tag
  invariant, Windows drive-path fix (#460).
- **alpha.17** — real-browser hydration coverage, defined 500 results with
  `RenderError` diagnostics, entry-descriptor single-instantiation, build
  helpers to `element/build-utils`, mechanical version-anchor gates.
- **alpha.18** — second audit sweep (ADR-0117): `reflect: true` write-loop
  fix proven in real browsers, one CEM admission plan across dev/SSR/SSG,
  the 500 contract wired to consumers (failed pages never ship nor enter the
  ISR manifest), `prefers-color-scheme` honored, router guards on history
  traversal, `renderIntent.streaming` removed, ~20 dead-code deletions.
- **alpha.19** — third audit sweep (ADR-0118, 26 issues): combination-path
  fixes (reflect removal × default, popstate redirect × block, For token ×
  separator smuggling), export-star seams closed with explicit type lists,
  gate mechanization for every audit blind spot, `HYDRATION_STRATEGIES`
  single-sourced, release executor hardened with resume orchestration tests.
- **0.41.0** — ADR-0119 scoped freeze; adapter-vite internal subpaths
  pruned; aggregate migration guide published; the release verifier and
  version guards made stable-line-aware; seven-day P0 watch on the 0.41.x
  patch line starts at this release.

## The site, rebuilt on itself

The openElement site was rebuilt with the v4 "view-source editorial"
language: JetBrains Mono + Instrument Serif display pairing, squared control
geometry from the token layer, zero theme hardcodes (mechanically gated),
framework-dogfooded i18n (`@openelement/app/i18n`), a real node-edge package
graph, registry-style API/changelog/roadmap pages, and a bilingual
`/guide/migration`. The homepage hero's title-clipping bug is fixed at the
layout level.
