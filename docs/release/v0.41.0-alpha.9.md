# v0.41.0-alpha.9

Alpha.9 is the coherent five-package OpenElement release. It replaces the
planned beta.4 name so the release label remains honest while external adoption
can still drive breaking changes.

## Highlights

- Collapse the public product from eleven packages to five: `element`, `app`,
  `adapter-vite`, `create` and optional `ui`.
- Deepen Element, App and Adapter boundaries while removing retired consumer
  imports, compatibility hooks, duplicate protocols and unused exports.
- Repair the packed npm starter and align generated projects around
  `dev`, `check`, `test`, `build` and `preview`.
- Move Reader and Mastodon dogfood to packed public interfaces and strengthen
  Node, Workers, third-party WC, artifact and release-truth evidence.
- Rebuild `@openelement/ui` around a smaller set of proven primitives.
- Redesign openelement.org as a cinematic Web Standards Lab and migrate every
  current subpage to shared hero, reading, rail, section and artifact systems.
- Add cross-browser, accessibility and 240-snapshot visual regression coverage
  for the new website.

## Breaking changes

- The former `core`, `signal`, `router`, `protocol`, `content` and `ssg`
  packages are no longer supported consumer surfaces.
- JSX authoring moves to `@openelement/element`; application authoring belongs
  to `@openelement/app`; build ownership belongs to
  `@openelement/adapter-vite`.
- Deprecated UI and compatibility exports removed during convergence are not
  carried forward as wrappers.

## Migration

Use these product entries:

```ts
import { defineElement } from '@openelement/element';
import { defineApp, definePage } from '@openelement/app';
import { buildApp } from '@openelement/adapter-vite';
```

Create a new application with:

```sh
deno run -A npm:@openelement/create@0.41.0-alpha.9 my-app
```

## Release history note

npm beta.1 through beta.3 remain immutable withdrawn partial artifacts. There
is no active beta.4 release line. External adopter pilot #390 remains open and
continues to inform when the project can make a stability commitment.
