# v0.40.1 Release Evidence

## Summary

v0.40.1 is the release-closure hotfix for the v0.40 product-line cleanup. The
v0.40.0 package line published to JSR, but post-publish consumer smoke exposed a
starter dependency gap: the generated app's SSR bundle imports `marked` through
the content pipeline, while the generated `deno.json` did not declare it.

JSR package versions are immutable, so the fix cannot be applied by replacing
`@openelement/create@0.40.0`. v0.40.1 carries the same product-line cleanup
truth plus the corrected starter import map.

## Changes

- Declare `marked` in the generated starter `deno.json`.
- Update `@openelement/create` template tests for the additional starter import.
- Keep the 11-package v0.40 product graph unchanged.
- Keep v0.41 planned as the npm-only distribution line.

## Verification

Local verification before release:

- `deno test --allow-read --allow-write --allow-run --allow-env --allow-net packages/create/__tests__/cli.test.ts`
- `deno task consumer:local`
- `deno task publish:dry-run`
- `deno task autoflow:ci`

Release closure requires the `main` branch `Publish to JSR` workflow to publish
the v0.40.1 package line and pass post-publish consumer smoke.
