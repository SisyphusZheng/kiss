# v0.41.0-alpha1 Version Plan - Audit-Driven Slimming

## Objective

Apply the over-engineering audit findings to `dev` as the first v0.41 alpha.
Delete speculative surfaces, collapse single-implementation abstractions, remove
unused dependencies, fold duplicate utilities, and restore `@openelement/protocol`
as a minimal type-only contract layer. Scope is slimming only; correctness and
behavior stay unchanged.

Net result: 11 packages (from 10 after initial protocol deletion back to 11
with type-only protocol layer), ~2,000 net lines removed, 3 runtime dependencies
removed (`alien-signals`, `esbuild`, `typescript`).

## Governance

- Autoflow3 remains the release control plane and is **out of scope** for this
  cleanup (needed for Codeberg sync).
- All cuts are source-only unless tests directly test the removed surface.
- Deleted tests must be matched by equivalent coverage on retained code or
  acknowledged as accepted loss for removed features.
