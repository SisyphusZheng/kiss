# v0.43.2

**Runtime and failure-recovery closure for the frozen 0.43 line.** This patch
contains the bounded fixes confirmed by the final 0.43.x stabilization audit.
It adds no feature train, public package, database migration, or breaking API.

## What changed from v0.43.1

### Framework runtime robustness

- The shared Node Fetch bridge now propagates client aborts into
  `Request.signal`, cancels request and response streams on disconnect, waits
  for `drain` under write backpressure, and removes lifecycle listeners after
  normal completion. The start CLI and generated standalone server still use
  the same single-sourced bridge (#1136).
- `definePreactIsland()` now keeps rendering ownership inside Preact for
  updates and teardown. Real detaches unmount exactly once, reconnects retain
  one live tree, and same-turn DOM moves do not spuriously destroy the island
  (#1135).
- Disposing the client router now invalidates pending programmatic and browser
  guards. Late guard results, redirects, and rejection recovery can no longer
  mutate history or notify a disposed application (#1143).
- Fetch-channel action failures always retain the frozen envelope. Top-level
  `undefined`, functions, symbols, BigInt values, and circular data degrade to
  `data: null` while preserving the author status in both Hono development and
  Nitro production builds (#1144).

### Supabase × Cloudflare reference SaaS recovery

- Notes refresh an expiring Supabase access token through a same-origin,
  non-cacheable server endpoint backed by the HttpOnly cookie session.
  Realtime receives the replacement token in-band, reconciliation retries once
  after a 401, and refresh tokens never enter DOM or client JavaScript (#1139).
- Upload finalization now records durable deletion intent before compensating
  Storage operations. Failed removal remains retryable, successful removal
  completes the tombstone, and quota ownership is never released while an
  object may remain (#1138).
- Stripe webhook raw-body processing is a single bounded stream read. It
  cancels immediately above 1 MiB, owns a finite stalled-body timeout, preserves
  the exact verified bytes, and rejects dishonest `Content-Length` values
  without contacting Stripe or persistence first (#1145).

### Tests, documentation, and release discipline

- The public-interface snapshot now fingerprints reachable declaration shapes,
  so changing a member of a re-exported public type fails the gate while
  private implementation bodies remain free to change (#1137).
- A clean source checkout can run the root test task directly: generated www
  content is an explicit prerequisite and the separately configured Supabase
  starter runs through its own task boundary (#1142).
- Current bilingual documentation now describes the published 0.43 contracts,
  maintenance-mode policy, and actual SPA option import pattern instead of
  stale 0.42/0.44 claims or the intentionally private `SpaAppOptions` type
  (#1140, #1141).
- Hono/Nitro request-time parity now runs behind a test-owned loopback listener
  with Vite WebSockets disabled. The canonical test succeeds with network
  permission restricted to `127.0.0.1` and `localhost`; it no longer probes or
  binds wildcard interfaces (#1147).

## Compatibility and upgrade notes

1. Bump all five `@openelement/*` packages together to `0.43.2` and refresh
   the lockfile. The Node 24+ generated-server floor is unchanged.
2. No public export was removed or added. Existing 0.43.1 applications require
   no source migration.
3. The Supabase starter still has 23 immutable migrations. This patch adds no
   migration and requires no remote schema apply.
4. Preact remains an opt-in renderer bridge through
   `@openelement/app/preact`; it is not the core component contract. Fresh
   remains a separately qualified host-framework interoperability example and
   is not a runtime dependency of OpenElement.

## Qualification

- The 12 v0.43.2 issues (#1135–#1145 and #1147) have targeted boundary or
  failure-injection coverage.
- The root test task passes 1,571 framework/tool/example tests plus 136 tests
  under the starter's independent configuration.
- Adversarial runtime acceptance covers Node abort/backpressure/cancellation,
  Preact move/detach/reconnect cycles, router disposal during pending guards,
  Hono/Nitro action-wire parity, Stripe and Notes failure paths, and upload
  Storage/RPC compensation.
- Ten 500-request keep-alive stress runs retain one socket per run, stable file
  descriptor counts, no positive listener growth, and converging post-GC heap
  growth.
- Generated Node and Wrangler 4.123.0 local-workerd outputs produce
  byte-identical workspace and Notes HTML against a loopback Supabase fixture.

  https://github.com/open-element/openelement/compare/v0.43.1...v0.43.2

External provider claims remain deliberately narrow: this patch does not claim
new real Stripe delivery, production Cloudflare deployment, SMTP/OAuth, or

baseline; v0.43.2 changes are qualified locally without remote schema or
