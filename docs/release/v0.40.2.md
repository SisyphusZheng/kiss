# v0.40.2 Release Evidence

## Summary

v0.40.2 is the release-closure hotfix for the v0.40 product-line cleanup after
the v0.40.1 JSR post-publish consumer smoke exposed one more generated starter
dependency gap.

v0.40.1 fixed `marked`, but the generated SSR bundle also imports
`@preact/signals-core` through the default signal engine. JSR versions are
immutable, so the starter dependency fix must ship as v0.40.2.

## Changes

- Declare `@preact/signals-core` in the generated starter `deno.json`.
- Update the create package template test for the additional starter import.
- Keep the 11-package v0.40 product graph unchanged.
- Keep v0.41 planned as the npm-only distribution line.

## GitHub Release Note Draft

### v0.40.2 - Starter Signal Dependency Hotfix

v0.40.2 completes the v0.40 cleanup release line after JSR post-publish consumer
smoke found that generated starters also need the default signal engine
dependency in their import map.

Fix:

- generated starters now declare `@preact/signals-core`, which is required by
  the v0.40 default signal engine during SSR/SSG builds.

The package graph, product scope, and v0.40 cleanup decisions are unchanged from
v0.40.0 and v0.40.1.
