# v0.40.2 Release Evidence

## Summary

v0.40.2 is the closure release for everything after v0.39.0. It represents the
full v0.40 product-line reset plus the two post-publish starter dependency
fixes required to make the JSR consumer smoke pass.

v0.39.0 established the framework RC and four-product matrix. v0.40.x turns
that RC into a smaller current product line:

- Elements
- UI
- Framework
- Protocols

The final published closure version is v0.40.2 because JSR package versions are
immutable. v0.40.0 and v0.40.1 published, but post-publish consumer smoke found
missing generated-starter dependencies. v0.40.2 carries the same product-line
cleanup plus the complete starter import map.

## Changes Since v0.39.0

### Product-Line Reset

- Reduced the active workspace to 11 packages.
- Removed Hub, RPC, CEM, compat-check, Lit/React/vanilla interop adapters,
  standalone runtime, standalone style-sheet, and standalone i18n from the
  current package graph.
- Kept `@openelement/ssg` as an adapter-agnostic SSG engine.
- Moved i18n into the app surface as `@openelement/app/i18n`.
- Kept historical material out of current product truth; git history remains
  the source for old SOP, NextVersion, Hub, and review material.

### Public Package Surface

- Renamed public package names to singular:
  - `@openelement/elements` -> `@openelement/element`
  - `@openelement/protocols` -> `@openelement/protocol`
  - `@openelement/signals` -> `@openelement/signal`
- Promoted `@openelement/element` into the component-authoring facade for
  `OpenElement`, `StyleSheet`, islands, and signal authoring.
- Removed compatibility re-export packages for the deleted/renamed surfaces.

### Preact, Signals, And Islands

- Added optional Preact island support under `@openelement/app/preact`.
- Set `@preact/signals-core` as the default signal engine for v0.40.
- Kept `alien-signals` available as an optional engine through
  `@openelement/signal/alien-engine`.
- Preserved Fresh as a comparison target only; v0.40 does not adopt Fresh
  routing or server runtime.

### Build And Runtime Foundation

- Deepened the Vite + Nitro path.
- Proved real Nitro output for Node and Cloudflare Workers.
- Kept SSG as a reusable build engine through `@openelement/ssg`.
- Kept generated starters on the one-command build path through
  `@openelement/adapter-vite`.

### Governance And Repository Hygiene

- Replaced old AutoFlow2 control surfaces with AutoFlow3 as the workflow,
  gate, evidence, and release-state control plane.
- Added or hardened checks for:
  - package surface
  - package graph
  - repo hygiene
  - workflow slimming
  - docs/current truth
  - text integrity
  - type safety
  - signal protocol boundary
- Enforced 0 explicit `any` in active TS/TSX.
- Reduced active workflows to the slim current set.

## v0.40.1 And v0.40.2 Closure Fixes

v0.40.0 published to JSR, but post-publish consumer smoke found that generated
starters missed `marked`, which is required by the content pipeline during
SSR/SSG builds. v0.40.1 added that dependency.

v0.40.1 then published to JSR, but post-publish consumer smoke found that
generated starters also missed `@preact/signals-core`, which is required by the
v0.40 default signal engine during SSR/SSG builds. v0.40.2 added that
dependency.

## Compatibility Notes

- This is a breaking cleanup release.
- Removed packages are not kept as compatibility re-export packages.
- `@openelement/i18n` is now represented by `@openelement/app/i18n`.
- `StyleSheet` now lives in `@openelement/core/style-sheet` and is re-exported
  from `@openelement/element`.
- `@preact/signals-core` is the v0.40 default signal engine.
- v0.41 is planned as the npm-first distribution line.
