## Summary

v0.41.0-alpha.6 hardens the App/protocol architecture and closes the alpha.6
cleanup audit. It makes OpenElement App own RouteGraph, RenderPipeline,
RequestContext, AssetManifest, IslandManifest, DeploymentTarget, and Deno
Desktop target contracts, while keeping Vite, Hono, Nitro, and Deno Desktop as
official adapters/drivers.

## Changes

### Front-half cleanup audit closure

- Eliminated duplicate implementations across packages (#226):
  - `fileToTagName` in `@openelement/ssg` now delegates to `pathToTagName` in
    `@openelement/core`.
  - `@openelement/core/island-transform` reuses the shared path-to-tag-name
    helper and normalizes unsafe characters to valid custom element names.
- Removed redundant dependencies, configs, and tooling helpers (#227):
  - Deprecated `writeJson` in favor of `formatJson` with a deprecated alias.
  - Aligned `runWithOutput` options API with `runCommand`.
  - Fixed `git ls-files` quoting with `-c core.quotepath=false`.
- Dropped the unused `packages/ssg/src/custom-element-name.ts` surface.

### Product truth and ADR closure

- ADR-0110 is accepted: public product doctrine is now
  `Web Components Fullstack Framework + Basic Element`.
- ADR-0111 is accepted: `@openelement/app` owns RouteGraph, RenderPipeline, and
  RequestContext; official adapters implement those concepts.
- Synced README, STATUS, ROADMAP, VERSION_PLAN, and website content.

### Trust-boundary and CodeQL cleanup

- Closed CodeQL/code-scanning backlog (#186 through #191).
- Added admitted module-specifier boundary for generated island dynamic imports.
- Shared CodeQL-recognized JavaScript literal escaping between generated client
  and server entry code.

### Reader regression dogfood

- Promoted the Deno Desktop Reader from working proof to regression-grade
  dogfood evidence.
