## Highlights

- Correct query decoding and the SPA page-host loader/action contract.
- Restore dialog sibling inert state and unify theme propagation.
- Make Element the type-only protocol authority for Adapter Vite.
- Delete verified dead DSD, CEM, route-scanner, and UI escape internals.
- Restore clean Nitro Workers proof and semantic visual smoke.
- Exclude adapter tests and fixtures from npm artifacts.
- Raise publishable runtime coverage to 69% lines, 81% branches, and 72%
  functions with regression tests on audited paths.
- Split release preparation from publication of an already-reviewed,
  main-CI-green commit.
