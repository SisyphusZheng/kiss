# v0.41.0 Stable-Readiness Dossier

## Alpha.15 interface baseline

The committed five-package snapshot is checked by `deno task interface:snapshot`.
`package-artifacts:check` verifies the packed ESM artifacts; package-surface and
consumer gates reject internal or retired imports.

| Surface      | Stable-candidate commitment                         | Evidence                              |
| ------------ | --------------------------------------------------- | ------------------------------------- |
| Element      | `defineElement`, JSX, DSD and documented subpaths   | Element tests and packed snapshot     |
| App          | `definePage`, `defineApp`, route descriptors        | App authoring and SPA tests           |
| Adapter Vite | `buildApp`, Vite/Nitro public subpaths              | build, Nitro and consumer gates       |
| Create       | exact-version starter lifecycle                     | packaged and published-consumer gates |
| UI           | optional but supported public Web Component surface | UI tests and snapshot                 |

## Support and compatibility

- Browser baseline: current Chromium, Firefox and WebKit with native DSD; see
  `docs/current/BROWSER_BASELINE.md`.
- Runtime baseline: Deno and Node ESM consumer paths; Nitro Node and Workers.
- Public errors use documented stable generic forms; implementation/internal
  subpaths remain unsupported until a separate stable decision explicitly adopts
  them.
- Upgrades are version-coherent across all five packages. Rollback means pinning
  a prior immutable npm prerelease, never rewriting a tag or package version.

## Stable decision boundary

This dossier is an alpha interface rehearsal, not a stable-release approval.
#390 remains open for real external adopter evidence and #37 remains the final
`0.41.0` decision gate.
