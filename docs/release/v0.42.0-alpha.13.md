# v0.42.0-alpha.13

Standards-as-seams train + TP-6 freeze preparation. 16 issues closed
(#603–#610, #856–#860, #863–#867); ADR-0123 documents the plan.

## Highlights

- **Morph robustness (the alpha.7 debt, all of it)**: the enhance/island
  client is now a real tested module instead of a 400-line string template
  (#610); focus, scroll and form-control state survive enhanced updates
  (#603); nested DSD templates instantiate recursively (#604); `open:ready`
  fires for every strategy bucket (#605); island scheduling has a single
  owner (#606).
- **Route standards**: all route matching is WHATWG URLPattern — the SPA
  client router and the generated server matcher share one semantics
  (#856); `renderIntent.mode` is now honestly `'static' | 'dynamic'` with
  the `'auto'` alias gone (#609).
- **Server seams**: a WinterCG-shaped fetch middleware contract
  (`middleware.use`, `(request, next) => Response`) runs identically in
  dev, `start`, fixtures and Nitro (#858); nitro-mount is a near
  pass-through on Nitro v3's native `Request` (#857); `cli/preview` merged
  into `cli/start --mode=preview` (#859).
- **Protocol**: fetch-channel error responses are RFC 9457
  `application/problem+json` — including the CSRF 403 (#863). This is the
  shape ADR-0122 will freeze at the 0.42.0 stable decision.
- **Components**: `open-input` is a real native-form citizen
  (ElementInternals: setFormValue + validity pilot, #864); `open-dropdown`
  moved to the Popover API with CSS anchor positioning (#865).
- **Site search**: full-text, ranked, bilingual via Pagefind — replaces
  the title-only bespoke index (#867).
- **TP-6 preparation**: migration note (`docs/release/v0.42.0-migration.md`),
  zero-cost upgrade proof with honest normalization disclosure, ETag
  revalidation design note (#866).

## Upgrade notes

- `renderIntent: { mode: 'auto' }` is removed — use `'static'` (the
  default) or `'dynamic'`.
- `cli/preview` is gone — use `cli/start --mode=preview`.
- Fetch-channel error JSON is now `application/problem+json`
  (`type/title/status/detail`); `fail()` 422 payloads are unchanged.
- `nitro-mount` now expects the Nitro v3 event shape (`{ req, context }`)
  and returns a standard `Response`.
- The generated request-time matcher requires URLPattern at runtime
  (Deno native; Node ≥ 23.8).
