## What happened

`v0.41.0-alpha.7` shipped the networked desktop dogfood foundation and the
first wave of runtime hardening (see the GitHub release below for the full
change list). The npm publish on 2026-07-07 was interrupted after 8 of the
then-11 packages:

- ✅ Published at `0.41.0-alpha.7`: `protocol`, `router`, `signal`, `core`,
  `element`, `app`, `ssg`, `content`.
- ❌ Never published at this version: `create`, `adapter-vite`, `ui`.

Because npm versions are immutable, the missing packages could not be added
after the interrupted publish, so the coherent package graph was released as
`0.41.0-alpha.8` instead. Do not adopt alpha.7 as a coherent package set.
