# OpenElement v0.41.0-alpha.14 Release Recovery Plan

## Purpose

`0.41.0-alpha.14` is a recovery prerelease after the
`0.41.0-alpha.13` publication completed npm upload but failed the final
published-consumer closure.

Alpha.13 source implementation is complete. The remaining failure was caused by
the published `@openelement/create@0.41.0-alpha.13` artifact using caret
prerelease ranges, allowing SemVer resolution to select `0.41.0-beta.3`.

PR #449 fixes the release train by enforcing exact package versions in generated
starters and consumer validation.

Alpha.14 exists only to publish the corrected immutable npm artifacts and
complete the missing evidence loop.

## Scope

Included:

- Re-release corrected packages as `0.41.0-alpha.14`
- Publish corrected Create starter template
- Verify exact package resolution
- Complete consumer validation
- Produce final GitHub/npm/tag evidence

Not included:

- New framework features
- API redesign
- Additional technical debt work beyond alpha.13 completed scope
