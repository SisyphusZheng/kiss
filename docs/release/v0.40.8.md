# v0.40.8 Cleanup-Train Patch

## Summary

v0.40.8 is a cleanup-train patch on the v0.40.7 baseline. It removes the legacy
Linear UI compatibility surface from `@openelement/ui`, migrates the last
internal consumer to the canonical Open Props UI, hardens the E2E server
strategy against local port conflicts, and extends the audit-driven cleanup to
`as unknown as` and non-null assertions. This release introduces no new product
feature and makes no default runtime, signal-engine, or package-topology change.

## Changes

### Legacy Linear UI Surface Removal

- Delete `open-button-linear`, `open-card-linear`, `open-input-linear`,
  `open-nav-linear`, `open-badge-linear`, and `linear-token-sheet` source files
  from `packages/ui/src/`.
- Remove their public exports from `packages/ui/src/index.ts`.
- Remove their subpath exports from `packages/ui/deno.json`.
- Remove their manifest declarations and modules from
  `packages/ui/src/manifest.ts`.
- Remove their smoke and component tests from `packages/ui/__tests__/`.
- Update `packages/ui/README.md` to state there is no Linear compatibility
  layer and list only canonical Open Props subpaths.
- Migrate `www/app/islands/scroll-reveal.tsx` from `linearTokenSheet` to
  `openPropsTokenSheet`.

### E2E Server Strategy

- Enable `reuseExistingServer: !process.env.CI` in
  `www/e2e/playwright.config.ts` so local runs reuse an already-running Deno
  server instead of failing on port conflict.
- Update `www/e2e/static-server.ts` to detect an occupied port and fall back to
  the next available port, logging the actual listening URL.

### Code Quality / Type Safety

- Maintain 0 explicit `any` in active TS/TSX.
- Reduce unnecessary `as unknown as` and non-null assertions in tests and
  production code, starting with the `packages/ui` test harness and the most
  obvious hotspots in runtime packages.
- Replace ad-hoc test DOM casts with typed helper interfaces where practical.

### Documentation and Version Governance

- Rewrite `docs/current/VERSION_PLAN.md` for the v0.40.8 cleanup-train patch.
- Add `docs/release/v0.40.8.md` release notes.
- Update `docs/roadmap/ROADMAP.md` version ladder and v0.40.8 section.
- Update `docs/status/STATUS.md` active line section.
- Bump workspace package versions and import maps from `0.40.7` to `0.40.8`.
- Update `README.md`, `README.zh.md`, `docs/governance/PROJECT_WORKFLOW.md`,
  `www/app/data/version.ts`, and public route metadata to the v0.40.8 line.
