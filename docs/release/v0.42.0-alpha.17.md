# v0.42.0-alpha.17

Registration-decoupling train. The alpha.17 architect final review found
the silent definePage render bypass (#960) still latent in the starter
pattern; this release implements the decided fix (Option 2, ADR-0128) and
lands the review's hardening and documentation set.

## Highlights

- **Registration decoupling (#960, ADR-0128)**: a route module whose
  default export is `definePage` now registers its page class under the
  route-path-derived fallback tag, so the definePage render — with its
  `request` context and the data channel behind `useActionData()` — always
  runs. Previously, a route combining `export const tagName` + a same-tag
  module-level `defineElement` + a `definePage` default export silently
  bypassed the page render at SSR. The `tagName` export now only names the
  content element; a definePage route whose `tagName` export is never used
  gets a one-time migration note at scan time.
- **Error-path hardening**: the bare-tag SSR fallback can no longer be
  crashed by a throwing/flaky getter on the props that forced the
  fallback; the depth-limit trip no longer logs once per bubbled
  function-component frame; the render-failure fallback shape is
  single-sourced across the serialize/render/instantiate catch paths.
- **Standalone server parity**: `dist/server/serve.mjs` serves CSS with
  the same `Content-Type` as `deno task start`, pinned by a drift test.
- **Scanner hygiene**: the missing-`tagName` note no longer fires for
  `.mdx` routes (they never carry one by design, #954).

## Upgrade notes

One breaking change on the unfrozen alpha surface:

- **SSR markup gains one wrapper element on shape-1 pages** (#960): pages
  whose route module self-registers a content element under the exported
  `tagName` now render that content element _inside_ the fallback-tag page
  element (e.g. `<home-page>` becomes `<index-page><template
  shadowrootmode><home-page>…`). Hydration markers, the morph client and
  island behavior are unchanged (the full fixture e2e, starter-smoke and
  visual-baseline suites pass), but user CSS or test selectors that target
  the old root tag must retarget to the fallback tag or the content
  element. Details: `docs/release/v0.42.0-migration.md`.

Otherwise upgrade by moving the five package specifiers to
`0.42.0-alpha.17`. Minimum Deno version is 2.8 (CI pins 2.9.x).
