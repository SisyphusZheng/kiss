# v0.41.0-alpha.12 Version Plan — Audit Remediation and Release Blockers

> Source audit: `deliverables/software-company/openelement-audit-0.41.0-alpha12-2026-07-14.md`
> (86 findings: 13 high / 30 medium / 43 low). Alpha.12 owns the 13 high-severity
> release blockers. Mediumseverity work moves to alpha.13; low-severity debt is
> tracked in #435.

## Objective

Close the 13 high-severity findings from the 0.41.0-alpha12 full code audit before
the alpha.12 release. The audit found three classes of release blockers:

1. **Core runtime bugs** in `packages/element` (infinite loop + broken error recovery).
2. **SSG/build pipeline defects** in `packages/adapter-vite` (command injection, route
   encoding, Node-environment crash).
3. **Contract-checker false positives/bypasses** and **zero-tested release tooling** in
   `tools/`, plus a coverage blind spot that leaves ~9,360 lines of infrastructure
   code unmeasured.

Alpha.12 adds no features. It zeroes out the release blockers and re-establishes
trust in the contract and release toolchain.

## Dependencies

- Base: `v0.41.0-alpha.11` (commit `358a6505`, npm alpha.11 + dist-tag verified).
- Audit report: `deliverables/software-company/openelement-audit-0.41.0-alpha12-2026-07-14.md`.
- Gate matrix: `deno task test` / `deno task typecheck` / `deno task lint` +
  `deno task test:coverage:check`.
- PR base branch: `dev` (alpha.12 train merges into `dev`).

## Workstreams

### A. Core Runtime Bug Fixes (element)

- #428: fix `signal-context` infinite loop when consuming an unprovided context
  inside Shadow DOM, and fix `ErrorBoundary` retry button (`onclick` → `onClick`).
- Add `signal-context.test.ts` covering cross-shadow-boundary lookup and the
  no-provider-in-shadow case.

### B. SSG / Build Pipeline Hardening (adapter-vite)

- #427: replace `execSync` string-concat `deno info` with `execFileSync` array
  args (command injection); complete dynamic-route segment encoding for `#?&%`;
  adapt `Deno.cwd()` → `process.cwd()` for pure-Node Vite runs.

### C. Contract Checker Correctness (tools)

- #424: strip inline comments before `as any` matching in
  `check-type-safety` / `check-architecture-contract`; restrict
  `deno-api-free:ignore` to file-leading directives in `check-package-artifacts`;
  make `check-critical-path-tests` actually run suites instead of text matching.

### D. Release Tooling Test Backfill (tools)

- #426: add unit tests for `lib/package-graph.ts` (import extract / cycle detect /
  topo sort / publish order), `publish-npm.ts` `deriveDependencies` (and fail on
  missing version instead of defaulting `0.0.0`), `bump-version.ts`
  `parseVersion` / `validateVersionStep` (with rollback detection).

### E. Coverage Measurement Extension (tools)

- #425: extend `coverage-summary.ts` `isProductionPackageSource` to include
  `tools/lib/`; set an initial tools/lib threshold and document it.
