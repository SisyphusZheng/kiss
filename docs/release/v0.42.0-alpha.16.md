# v0.42.0-alpha.16

Starter-first remediation train. The round-3 audit's headline finding was
that the monorepo fixtures were green while the published starter was
broken; this release closes the remaining gaps (issues #915–#959) and pins
each fix with packed-starter e2e gates that run in CI (#934, #936).

## Highlights

- **CSRF and enhanced forms**: request-time mutation endpoints enforce a
  coherent Origin policy matrix — cross-site POSTs are rejected while
  same-origin native form posts (`Origin: null` + `Sec-Fetch-Site:
  same-origin`) pass, so progressive enhancement works without JavaScript
  (#921, #938); enhanced forms morph correctly into slotted light-DOM pages
  (#937).
- **Island runtime**: `hydrate: 'only'` islands bind events and signals
  instead of rendering inert (#939); function-mode `defineIsland` islands
  re-render on signal change (#940); matched DSD hydration keeps keyed `For`
  lists reactive via per-item boundary markers (#917); clicks landing
  between first paint and island hydration are captured and replayed once
  (#942 — capture starts when the generated client entry executes; earlier
  clicks are still lost).
- **ErrorBoundary**: render failures inside a subtree are auto-captured by
  the nearest `ErrorBoundary` (ADR-0053 Layer 2) and bubble outward when a
  fallback itself throws (#919).
- **Routing/SSR semantics**: `notFound()` from a page render propagates to a
  real 404 status (#922); unmatched request-time paths render a styled 404
  page with `Cache-Control: no-store` (#923); successful GET pages relax to
  `private, no-cache` so the UA restores scroll position and can use bfcache
  (#943).
- **element runtime**: `<style>`/`<script>` text children serialize as raw
  text (#932); `data:` URIs are allowed on `img src` only, not `href` (#929);
  keyed `For` semantics locked with its AbortSignal teardown leak fixed
  (#915, #916, #918).
- **Build and dev chain**: dev serves the island client entry and overwrites
  stale SSR class registrations (#951, #952); pure-static dist drops the
  build-time SSR bundle (#953); `.mdx` route files render (#954); index
  routes keep clean URLs next to same-named directories (#956); request-time
  builds emit a standalone `dist/server/serve.mjs` so a built project serves
  itself with `node dist/server/serve.mjs` (#959).
- **Starter surface**: the dev task pins the same vite version as the import
  map (#927); the template ships working blog routes
  (`@openelement/generated/blog-data`), a styled 404 and a styled,
  progressively enhanced contact form; `deno task check` covers every
  generated route and island file.

## Upgrade notes

Two breaking changes on the unfrozen alpha surface:

- **`IslandOptions.strategy` renamed to `hydrate`** (#920, ADR-0127): the
  old name is deleted with no alias. Migration: rename `strategy` →
  `hydrate` at each element `defineIsland()` call site. App-side authoring
  via `defineIslandConfig({ hydrate })` is unaffected.
- **Head-injection sanitization tightened** (#931): `<base>` and `<meta
  http-equiv=...>` are now stripped from `headExtras`/head fragments, and
  raw `<script>` tags are rejected. Apps injecting a CSP meta or base tag
  through `headExtras` must move those into the document shell / SSG
  postprocess directly.

Otherwise upgrade by moving the five package specifiers to
`0.42.0-alpha.16`. Minimum Deno version is 2.8 (CI pins 2.9.x).
