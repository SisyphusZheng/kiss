# v0.40.0 Product-Line Cleanup Evidence

## Summary

v0.40.0 narrows the current product line to 11 packages and removes historical
Hub, RPC, CEM, compat-check, interop adapters, standalone runtime, standalone
style-sheet, and standalone i18n surfaces from the active repo shape.
`@openelement/ssg` remains as the adapter-agnostic SSG engine. Public package
names are singular (`element`, `protocol`, `signal`), active code enforces 0
explicit `any`, and AutoFlow2 historical implementations are removed in favor
of the AutoFlow3 control plane.

## Evidence Targets

- Package graph: 21 packages reduced to 11 current packages.
- Workflows: 8 workflows reduced to 4 active workflows.
- Docs: active docs limited to current truth, ADR, roadmap/status, release
  evidence, and archive index; `.github` templates no longer reference SOP/NextVersion.
- Hub: `packages/hub`, root `hub-index`, public Hub data, and Hub routes removed
  from the current product line.
- CEM/compat: `@openelement/ssg` keeps only internal CEM compatibility code
  needed for package detection.
- Signal engine: `@preact/signals-core` is the default engine;
  `alien-signals` remains available through `@openelement/signal/alien-engine`.
- AutoFlow3: CI and local gates use AutoFlow3 entry points only.
- AutoFlow3 patch automation: v0.40.0 cleanup-train release execution requires
  approval id `ADR-0105/v0.40.x-cleanup-train`.
- Type safety: `type-safety:check` gate asserts 0 explicit `any` in active
  TS/TSX across packages, tests, tools, and www active code.

## GitHub Release Note Draft

### v0.40.0 - Product-Line Cleanup

v0.40.0 is the product-line cleanup release for openElement. It turns the
v0.39 framework RC into a narrower, cleaner v0.40 product line and prepares the
project for the npm-first full-stack roadmap.

Highlights:

- collapsed the active workspace to 11 current packages;
- removed Hub, RPC, CEM, compat-check, Lit/React/vanilla interop adapters,
  standalone runtime, standalone style-sheet, and standalone i18n from the
  current package graph;
- retained `@openelement/ssg` as the adapter-agnostic SSG engine;
- renamed public packages to singular `@openelement/element`,
  `@openelement/protocol`, and `@openelement/signal`;
- made `@openelement/element` the component-authoring facade for
  `OpenElement`, `StyleSheet`, islands, and signal authoring;
- added optional Preact island support under `@openelement/app/preact`;
- made `@preact/signals-core` the default signal engine while keeping
  `alien-signals` available as an optional engine;
- removed AutoFlow2 historical implementations and kept AutoFlow3 as the
  workflow/gate/evidence control plane;
- added repo hygiene, text integrity, type-safety, package-surface, and
  workflow-slimming checks to keep the smaller product line from drifting.

Compatibility notes:

- this is a breaking cleanup release;
- removed packages are not kept as compatibility re-export packages;
- `@openelement/i18n` is now represented by `@openelement/app/i18n`;
- `StyleSheet` now lives in `@openelement/core/style-sheet` and is re-exported
  from `@openelement/element`;
- future v0.41 work is planned to replace JSR release closure with npm-only
  distribution.

Release validation:

- local repository gates passed before merge;
- Nitro Node and Workers proofs passed;
- local consumer smoke and publish dry-run passed;
- the `main` branch `Publish to JSR` workflow is the distribution closure gate
  for JSR publish and post-publish smoke.
