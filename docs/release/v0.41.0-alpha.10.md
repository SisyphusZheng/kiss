# v0.41.0-alpha.10

Alpha.10 is the usable five-package convergence release. It supersedes
alpha.9, whose npm metadata omitted runtime dependencies inherited from the
workspace root import map.

## Fix

- Materialize root import-map dependencies actually used by each package into
  its packed npm `package.json`.
- Restore Node ESM installation and execution for `@openelement/element` and
  `@openelement/app` consumers.
- Keep the `alpha` dist-tag and all current product documentation on the usable
  package line.

## Included convergence work

Alpha.10 also contains the complete alpha.8-to-alpha.9 convergence: the five
public packages, repaired starter, deep Element/App/Adapter interfaces, packed
dogfood, smaller UI surface and unified cinematic website.
