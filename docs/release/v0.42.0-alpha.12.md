# v0.42.0-alpha.12

Round-6 full-spectrum audit remediation train. All 112 findings from the
2026-08-02 round-6 audit (issues #810–#852) are fixed in this release; the
audit report lives at `docs/audit/2026-08-02-round6-audit.md`.

## Highlights

- **Correctness**: submitting a form whose post-action loader re-run throws a
  guard-vetoed `redirect()` no longer wipes the current page's data — the
  action path now mirrors the navigation path's #802 guard (#810). The SPA
  client router matches Hono-style `:param{.+}` catch-all patterns, so
  generated route manifests work end to end (#812). Malformed
  percent-encoded URLs are a defined 400 instead of a hung request or a
  crashed process (#823).
- **CSRF floor is now proven, not just present**: the generated action POST
  same-origin floor has real deny/allow e2e coverage — cross-site rejected,
  same-origin allowed, `OPEN_ELEMENT_DISABLE_CSRF=1` opt-out allowed (#811).
  This fulfils the TP-5.7 exit criterion.
- **Honest claims**: ISR is labelled as forward-compat/inert in 0.42 wherever
  it appears — homepage output showcase, `PACKAGE_SURFACE.md`,
  `ISR_KV_ADAPTER.md` (runtime not importable until 0.44), and the starter
  freshness page (#840, #842, #843). The security guide now documents the
  built-in CSRF floor and its opt-out instead of claiming no built-in
  protection (#815). The README separates shipped 0.42 request-time
  data/forms from 0.44 session/cache work (#852). The starter `headerNav`
  config actually renders (#829).
- **Gates that gate**: `verify-package-configs` performs a real version check
  instead of a tautological self-comparison (#824); the unreachable
  publish-order validation block is gone (#825); `stripComments` is
  string-literal aware so artifact scanning cannot be blinded by `//` inside
  a URL (#826); mojibake and stale-claim pattern lists are single-sourced
  (#827, #838); the five-package roster is derived from one constant (#828);
  version anchors cover the fresh example and reject published-version +
  in-flight wording co-occurrence (#813, #819); release evidence validates
  Previous ≠ Released (#822).
- **Docs truth**: ROADMAP / PROJECT_WORKFLOW / VERSION_PLAN agree on the
  published state again (#813); the v0.41.0-alpha.5/7/8/11/12 release
  evidence gaps are backfilled honestly (#822); CONTRIBUTING describes the
  real five-package layout and the real `.ts`-extension import style (#814).
- **Hygiene**: 23 dead SVG icons deleted (#831); the dead blue/teal/cyan
  token palette no longer ships in every page (#832); `data-ssr-props` is
  single-sourced (#836); dead exports, dead barrels and dead config swept
  across all five packages (#833, #834, #840, #841, #845–#852); the two
  desktop examples share one client router and topnav (#837); www component
  registration is uniformly idempotent (#851).
