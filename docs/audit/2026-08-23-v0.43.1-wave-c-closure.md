## Why the verdict is not `GO`

Exact-SHA AutoFlow CI and CodeQL passed, and the four new forward migrations
executed on both fresh and upgraded ephemeral Supabase projects with identical
schema output. The real-project matrix was then run twice without applying
migrations. Auth, session, Notes writes and the curl RLS matrix passed, but the
browser Realtime journey failed once on second-client delivery and once after
offline/online recovery while the island still claimed `subscribed`.

That evidence produced P2 #1134. Root-cause review found that the one-shot JWT
was correctly erased from the DOM after `setAuth`, but reconnect constructed a
new client from the now-empty DOM attribute and silently fell back to `anon`.
The application-owned remediation retains the token only in private element
memory and performs a stable-ordered, hard-capped Data API reconciliation on
subscribe and periodically thereafter. It still needs exact-SHA CI and two
green real-project repetitions. Linked-project migration check/apply also
remains blocked by missing dedicated repository credentials.

## Architecture and public-surface review

- The five-package graph remains acyclic and version-aligned at `0.43.0`.
- No public package entry exposes an `internal/` module path.
- The nested SSR fix is internal protocol plumbing; it adds no exported public
  symbol. Loader data moved from a public host field to an internal field in
  generated SSR code while SPA/manual page hosts retain the documented `data`
  fallback.
- Notes pagination and deletion reconciliation are reference-application
  capabilities, not framework ORM/outbox/session APIs.
- The DSD `data-*` serialization correction removes redundant hydration JSON;
  data attributes remain standard host attributes after upgrade.
- ADR-0140 freezes feature-train work after v0.43.1 while preserving compatible
  0.43.x fixes and allowing a future minor only through a maintainer-approved
  ADR backed by a cross-application need.

Result: **pass** (`arch:check`, `graph:check`, `package-surface:check`,
`interface:snapshot`, `type-safety:check`, `freeze:semantics:check`).
