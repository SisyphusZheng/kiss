# Homepage Spec

## Purpose

The homepage must sell the product by showing the product: Web Components,
Declarative Shadow DOM, routes, islands, packages, and product contracts.

## First Viewport

- Left: product statement, lede, primary/secondary actions, four proof points.
- Right: engineering artifact panel with code, render pipeline, and runtime map.
- H1: "Web Components full-stack framework."
- Product language: `Elements + UI + Framework + Protocols`.

## Sections

1. Hero artifact.
2. Four product pillars.
3. Application workflow: Author, Render, Hydrate, Serve, Prove.
4. System map: four-product matrix and package boundary sketch.
5. Entry paths: Guide, API, Roadmap.
6. Closing CTA.

## Layout Rules

- Container: max-width 1240px.
- Desktop hero: two columns.
- Tablet/mobile hero: stacked.
- Cards are used only for repeated proof points or entry paths.
- Code and diagrams are the visual assets.
- No decorative blobs, no marketing gradient hero, no external SaaS clone.
